# RentCraft
Coin Item Rentals in minecraft with coincard api


Depends on CoinCard plugin

CoinShop - https://github.com/FoxUshiha/CoinShop-Plugin
CoinCard - https://github.com/FoxUshiha/CoinCard

Commands:

/coinrent rent amount value (in coins) - while holding an item in your hand!

It's like coinshop but you need to pay by hour passing for items;
